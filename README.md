# Akdeniz

Antalya otobüs durakları için sade bir web uygulaması: en yakın durak, varış dakikaları, canlı otobüs konumu ve duraklar haritası.

- iPhone: Safari'de aç → Paylaş → **Ana Ekrana Ekle**
- Android: Chrome'da aç → menü → **Ana ekrana ekle**

Veri: Kentkart (Antalyakart'ın kullandığı servis). Harita: © OpenStreetMap katkıcıları, OpenFreeMap.
Bu uygulama resmi değildir; Antalya Büyükşehir Belediyesi, Antalya Ulaşım A.Ş. ya da Kentkart ile bağlantısı yoktur.
